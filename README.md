## Local Setup & Usage
Since this project uses pure static web standards, no compilation, package installation, or build steps are required.
### 1. Direct Browser Opening
Simply double-click [`index.html`](index.html) or open it directly in any modern browser (Chrome, Edge, Firefox, Safari).
### 2. Local Development Server
For optimal testing of geolocation and video streaming, serve the folder with any static local server:
**Using Python 3:**
```bash
python -m http.server 8000
```
Then navigate to `http://localhost:8000` in your browser.
**Using Node.js (`npx`):**
```bash
npx serve .
```
**Using VS Code:**
Use the **Live Server** extension to launch `index.html` with hot-reloading.
